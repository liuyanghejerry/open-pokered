# 一周目推进记录

## 完成标准与运行方式

目标是从 NEW GAME 正常游玩到四天王、冠军及结局流程；不使用冠军预设、
`warp`、`give_*`、`set_flag` 或直接编辑存档代替主线推进。
开发时使用 `--resume` 保存已走过的路线，最终以 fresh 全链运行作为结论。

```bash
cargo build --bin pokered-app --features debug-server
python3 -u scripts/playthrough.py --resume --until m12 --artifacts /tmp/first-clear-m12
```

`--artifacts` 留存每个实际执行的里程碑的状态、剧情标记、队伍和背包；
失败时另存 traceback、当时状态和游戏日志。每次尝试使用不同目录，避免覆盖证据。
续跑文件仍为 `scripts/.playthrough.sav` 和 `.playthrough.marker`。
