# PC 重新进入的默认选项

基底为当前 master `40ebaa763b440951368c8ec88b8c72bd6a463d75`，本修复只处理在通用 PC 菜单退出子电脑后，重新进入玩家物品 PC 或宝可梦寄存 PC 的默认选项。

原作依据：pret/pokered `fbcf7d0e19a3a2db505440d3ccd3d40ca996c15c` 的 `engine/menus/players_pc.asm` 中 PlayerPC，以及 `engine/pokemon/bills_pc.asm` 中 BillsPC_；每次进入均将 wParentMenuItem 清零。子电脑内部从列表返回时继续恢复保存的选项，不应将这种内部返回也重置。

原作实际按键两遍验证：玩家 PC 选 TOSS ITEM → 取消列表 → 退出子电脑 → 重新进入，回到 WITHDRAW ITEM；宝可梦寄存 PC 选 SEE YA! → 重新进入，回到 WITHDRAW。复刻修复前分别保留 TOSS ITEM、SEE YA!。第一次没有选择子功能就退出的原作试录仅为控制场景，未用它证明问题。

生产修改集中在一个文件，只在通用 PC 菜单进入子电脑时重建对应菜单状态；寄存 PC 保留当前箱号。核心测试验证玩家 PC 内部返回保留原选项、重新进入清零，及实际存储第 3 箱（索引 2）保持不变、不请求存档。

实际游戏以相同控制快照、正常按键进入 PC；未直接设置 PC 阶段。实际 master 与候选每种子电脑各录制两遍，全部 PNG 和状态 JSON 逐字节一致。候选重新进入后的画面逐字节等于同次运行最初的默认选项画面；玩家 PC 内部列表返回的画面仍保留所选操作。背包不变，未创建存档。前帧使用已冻结的 #167 提交 4508b74 运行文件，其整个 crates 源码与合入后的实际 master 40ebaa7 完全一致；这是源代码完全相同的运行文件，不称为新重建的 master 程序。

当前基底下 78 个单元/集成测试程序：3675 通过，0 失败，76 忽略。启动 m01–m03 及独立进程调试存档→CONTINUE 结果随验证摘要/日志提供。这些受控验证不等于自然主线通关；箱号索引 2 的检查来自核心回归，实际画面场景使用原夹具的第 1 箱。

四张前后截图对应相同的重新进入后第 20 帧。evidence.zip 包含原作记录、实际两侧两遍记录、源码、测试日志和摘要；PNG 按 SHA-256 去重，通过 png-files.json 还原原始路径，归档逐文件回读核对。ROM、模拟器状态、存档和运行文件不公开。
