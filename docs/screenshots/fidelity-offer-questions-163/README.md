# 三种钓竿及会长问句（163）

原作三个垂钓大师的“Do you like to fish?”和会长开场问句都由内层 PrintText 打印，以 DONE 返回，紧接 YesNoChoice。复刻先前需要额外按键结束问句；四处改用 printFieldText。会长后续长故事明确以 PROMPT 结束，因此仍须玩家按键后才能 GiveItem，自行车兑换券的发放流程保持该等待。

实际输入回归覆盖四处 YES/NO、物品/事件标志、对话收尾无残留，并在会长故事末页空等 12 帧证明不会提前发券。领取音效期间释放 A，遵循 HoldTextDisplayOpen；失败的初版测试重复按住 A 导致领取窗口保持，已修正测试驱动，没有取消音效或弱化窗口检查。

四处前后都实际 Continue 同一 SRAM，再受控清除四个已获得标志并移除自行车/兑换券、warp 到对应 NPC 下方。两版设置及辅助录制代码完全一致；Medium=3、初始 Up 0..19，A 20..39，后续只确认非最后页。最终输入由修复版先生成，再原样回放两边。第 1100 帧分别为 old/good/super/chairman 前后图；各两次 1200 帧的 PNG/输入/原始状态逐字节一致。master 停在前一段文字，不能据此宣称相同文字入口时刻或原作 LCD 时序。

三种钓竿菜单分别在 189/234/216 帧出现，会长在 446；修复版无需结束问句的额外 A。原作这四处本批仅核对汇编和终结指令，没有新增原作模拟器录制，明确不声称 CPU/LCD 帧一致。
