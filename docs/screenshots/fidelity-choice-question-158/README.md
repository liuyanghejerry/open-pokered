# 选项菜单保留问题文字

Safari 信息员的问题在复刻弹出 YES/NO 时消失，原作的 `PrintText -> YesNoChoice` 保留问题。共享 ShowDialogue 结束时，现在保存最后一页的显示状态；直接或嵌套选项菜单显示它，不让这份保留文本再次消费 A/B。选择完成、新台词开始或脚本结束会清除旧状态。JSON 快照包含该状态，旧 JSON 缺字段时按 None 兼容。原先没有保存的问题内容无法从旧快照凭空恢复。

前/后图均用原作一步额度 SRAM 通过真实 CONTINUE，随后明确结束狩猎并 warp 到有效柜台位置 `(3,4)`。固定 RNG=1，面朝左；相同硬件帧输入在 0/80 按 A，2/82 松开，截图为第 120 帧。前图来自实际 master `31b1eda3112514d6bc803af559ec7f7c9e20374f`，只添加同一录制测试辅助代码，生产前缀与 git 原文件一致。后图为最终修复源码。前/后各两次、每次 152 帧；608 PNG 和完整原始 JSON 重复逐字节一致，无状态字段掩码。原作参考图来自另一条真实移动/交互录制，保留原始例程调用和图块数据，不能当作绝对同帧比较。

实际游戏回归验证 Safari YES/A、NO/B 的台词分支、选择前 JSON 恢复、结束后不残留；博物馆多页售票问题保留最后一页，中间显示金钱框也不丢失。Safari 的交接和完成过程逐帧比较缓存/完整绘制。渲染缓存门禁读取同一份实际显示状态，避免把保留的问题当成无叠加层画面。CUT 的既有保留文本不参与新增的选择生命周期门禁。

最终核心 2,736 项、应用 208 项测试通过；26 个捕获辅助测试默认忽略。GBA 发布构建及原阈值下性能结果见附属文件。`evidence.zip` 内保留录制、源数据、源码、构建/测试日志和早期候选日志，每个条目 SHA-256 打包后全部重新验算。早期候选或失败命令不计入最终验证。
