# 钓竿与兑换券文字会话

三种钓竿和会长的实际领取会话使用原作的内层音效语义：打印领取文字后等待完整音效，保留同一窗口，不执行外层 A 保持或关闭。好钓竿音效后等待新的最终 A/B；另外两种钓竿和兑换券等待手动段落推进，清空文字区20帧后打印说明。普通地上拾取物品的自动关闭保持原行为。

四个NPC的开场、赠送、说明、拒绝、背包满和再次问候中的显式段落已接入共享printFieldParagraph；会长故事末尾的waitFieldPrompt只完成内层ProtectedDelay3/ManualTextScroll，不HoldA/Close。钓竿领取标记在赠送文字前设置，兑换券标记在说明打印完后、外层最终确认前设置。

实际输入回归覆盖成功/拒绝四NPC、背包满四NPC、完整PCM领取音效长度、音效中的B/方向短按、等待中JSON恢复、会长PROMPT后的A保持，以及最终等待和释放A。完整core2741/data262/app217/agent54通过；32个ignored包含诊断录制。GBA39源文件SHA与隔离检出一致，31项维持原始预算，未修改基线。
