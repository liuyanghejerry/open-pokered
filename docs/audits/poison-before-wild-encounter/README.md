# 第四步遇敌前的场外中毒

复刻把野生战斗排入队列后，跳过同一步的中毒扣血。原作 `home/overworld.asm:314–325` 先执行 `ApplyOutOfBattlePoisonDamage`，全队倒下则跳到 `HandleBlackOut`，否则才调用 `NewBattle` / `TryDoWildEncounter`。

本修复允许第四步同时请求中毒与遇敌，并让战斗等待中毒调用结束，包括每只昏倒提示的确认和四帧 BG 闪屏。全队倒下时丢弃本步预先选出的野生战斗，避免治疗或传送后重新开战。原有剧情、对话和传送的中毒门禁保留。
