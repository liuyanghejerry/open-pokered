# 破旧钓竿与好钓竿领取确认

原作先发放钓竿并设置领取状态，再打印赠礼段落。音效结束后，破旧钓竿等待下一段确认，好钓竿等待 NPC 对话的外层确认。修复保留这些边界、拒绝和满包分支。

`verification.json` 记录源码、二进制、原作／复刻控制和截图身份。`prepared-recordings.json.gz` 是准备存档对照；`paired-recordings.json.gz` 是最新 master 与独立候选的配对重录。截图使用同一存档、初始画面和绝对帧；两侧的对话确认前缀不同，各自重复两遍。字体保留 Fusion Pixel。

四个 `.sav.gz` 解压后可通过普通 CONTINUE 重放。候选覆盖成功、满包、拒绝、提前短按及长按 A/B，共 10 组各两遍，20 次保存后独立进程续玩。它们不代替完整新游戏回归。完整回归的状态见验证清单及 PR 说明。
