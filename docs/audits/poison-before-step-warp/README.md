# 第四步进门前完成场外中毒

从常青市 `(20,26)` 向右三步、向上一格进入宝可梦中心，第四步原本会因 `pending_warp` 而跳过中毒请求。原作 `home/overworld.asm:308–325` 的顺序是 Safari 步数、中毒、全队倒下、遇敌，再检查传送。

现在第四步保留原来的单一 `pending_warp` 目标，只暂存待播放的进出门声音；本步中毒与昏倒文字返回后，再播放声音并启动原有淡出。全队倒下在黑屏文字确认前取消原来的门，之后沿既有回城流程处理。Safari 时间到优先取消该门，不扣本步中毒血量。队伍仍只由 `SaveData.party` 持有；快照保存续接状态，普通读档和重置清除它。
