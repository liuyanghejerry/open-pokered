# 宝可梦笛仅解除睡眠

队伍有睡眠成员时，旧实现先唤醒睡眠成员，再无条件清空双方当前出场宝可梦的状态。因此本来中毒、灼伤、麻痹或冰冻的出场者也被治好。现在删除两次多余的清空操作；出场成员本来就是队伍条目，已有逐条睡眠处理足够。

## 原作与生产修复

原作 fbcf7d0e 的 `engine/items/item_effects.asm:1706–1772`：`ItemUsePokeFlute.inBattle` 调用 `WakeUpEntireParty`，并对两只出场者使用 `and ~SLP_MASK`。它只清睡眠位，保留其他状态。生产改动仅在 `BattleScreen::use_poke_flute` 删除两次无条件写入。现有音乐请求、道具数量和敌方回合接续保留；新增一个核心回归覆盖四种非睡眠状态的双方出场者及睡眠后备成员。

基线回归确实失败（Poison→None）；第一次基线构建因新 worktree 缺少 gfx 链接而失败，补齐已有资产链接后得到功能断言失败，两份日志均保留。
