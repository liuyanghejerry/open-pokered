# B29: Mirror Move live history and called-move timing

Original `engine/battle/used_move_text.asm:11–19` writes the actor's used-move byte immediately. `core.asm:3351/3361` and `5698/5707` clear it for Sleep/Freeze. `MirrorMoveCopyMove` at `4962–4984` reads that live byte and rejects both zero and Mirror Move itself. Original turn priority is selected at `348–399`, before `ExecutePlayerMove`/`ExecuteEnemyMove`; therefore Metronome choosing Quick Attack cannot move the actor earlier in the already ordered turn. Called-move effect dispatch at `3123–3129`/`5515–5521` follows the status check at `3091`/`5481`.

The prior production frontend resolved player's called move before the turn and updated `last_move_used` only after the full turn. The B28 enemy callback improved its placement but still read the previous turn's history. The same helper's four-step loop treated Mirror Move copying Mirror Move as success. Production probes linked against the pre-B29 native core library actually reproduced all three errors: first-turn slower Mirror Move leaves target HP400 rather than350; a sleeping faster actor with old Tackle lets Mirror Move deal22 instead of failing; Mirror Move copying Mirror Move has no failure text. Full output is `battle-called-history-before.log` (3/3 original-expectation cases fail, 0.01 seconds).

The fix seeds an explicit UsedMove volatile from legacy history, clears it at the Sleep/Freeze gates, and updates it immediately after a move passes status checks. Both called moves resolve natively after paralysis and before the move-specific continuous-move handlers. A defaulted game-neutral engine hook selects the resolved effect after BeforeMove, retaining original selected-action priority and running status gates once. Called-move narration survives the trainer-item adapter round trip.

`fidelity_called_history.rs` has six independent production regressions: both actor orders for current-turn Mirror Move; Sleep/Freeze clearing; Mirror Move rejecting Mirror Move; blocked Metronome consumes no selection RNG; Metronome→Quick Attack keeps original order; player-first Mirror Move→Poisonpowder preserves both caller/resolved narration across a Brock Full Heal round trip. Root integration ran all six tests successfully together with the other battle production fixtures (61 tests total, zero failures). Engine default behavior has its own regression, preserving all games which do not use called moves.
