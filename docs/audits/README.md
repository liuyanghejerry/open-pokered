# 审计材料存储约定

仓库保留简短结论、原作来源、可复现脚本、自动测试实际使用的最小夹具，以及视觉 PR 所需的前后截图。

逐帧录制、完整状态轨迹、压缩日志、运行报告和校验清单属于临时产物，不应提交。输出写入 `.task-tmp/` 或仓库之外，验证完成后及时删除，不用 `git add -f` 绕过忽略规则。

历史压缩记录及其专用校验器已从当前目录清理。旧说明中的录制文件名和哈希是历史测试描述，不代表文件仍随仓库提供。需要复查时，用对应脚本重新录制；需要与旧记录精确比较的 HoF 工具通过 `--controls` / `--reference` 接收外部临时文件，保留全部原有断言。

本次清理不修改共享 Git 历史，不移除源码／测试依赖的夹具或视觉 PR 截图。
