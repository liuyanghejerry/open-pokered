# START 菜单方向组合键

修复同一轮输入含方向和 A/B/START 时，菜单移动后立即选中或提前关闭的问题。原作 `home/window.asm:52–132` 返回实际采样位；`home/start_menu.asm:14–58` 先处理 UP、DOWN 并回到循环，只有独立按钮路径才选中、关闭和保存光标。单独 A/B/START、原有包围滚动和方向输入方式保持不变。

实际运行来源是主线 `e6efc43c40567712350dc0958c11d71e34d2dc4f` 与修复 `fabd39746c642287a10f5182aa680dd70f3e7ac9`；文档提交没有重新运行游戏。原作固定 `fbcf7d0e19a3a2db505440d3ccd3d40ca996c15c`，引擎 `e533a3d23a0cdbed1524a1ac91184733da4a6f7e`。两个实际来源的编译源码 2,713 份、GFX 702 份、引擎 981 份均通过运行前后校验。

实际核心专项 **29 通过、0 失败**，含四项新增组合键、首尾包围、UP/DOWN 同按和释放后独立按钮控制。另用同一物理 SRAM、同一份外部 `witness.rs` 分别链接两套实际 App 库，运行四次冷启动：每次 1,556 帧，总计 6,224 帧真实输入、6,228 条状态，四个程序自然退出 0，进程组均结束。它使用共享 `PokemonGame::update/draw` 和持久 `InputState` 的真实多键输入；单键 debug RPC 无法代替这个组合键验证。没有跳开场、现场状态改写、warp、运行态快照恢复或 seed 修改，静音路径沿用正常 Game 的 PCM 逻辑时钟。
