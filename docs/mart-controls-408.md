# 商店菜单按键、确认与音效

本批次独立建立在已合入的商店字段流程（PR #185）上。

## 修复行为

- BUY/SELL/QUIT、购买/出售列表及 YES/NO 选择停在边界，数量选择保留原作独立的循环规则。
- 普通菜单的 A/B 播放 PRESS_AB；数量选择与最外层退出确认保持无声。
- YES/NO 保留选中项并冻结后续输入 15 帧，再提交或取消交易。
- 交易提交后不打断仍在播放的确认音效；出售在收银音效期间保留原数量画面和背包显示，结束后才恢复物品列表。

同一输入的直接问题：从 YES 向上，主分支会翻成 NO 并取消；从 YES 连按两次向下又翻回 YES 并买下物品。修复后分别保持 YES 和 NO，资金和背包与原作的菜单边界一致。
