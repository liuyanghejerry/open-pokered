# 图鉴列表的组合按键修复

从 START 打开图鉴，按住 DOWN 再按 A，原作继续移动列表；修复前会误开 DATA 侧菜单。RIGHT+A 同样存在此问题。原因是 App 只转发新按下的 A，丢失仍按住的方向键，而原作 `JoypadLowSensitivity` 在出现新按键时报告完整 held mask。

此修复只调整列表新按键事件的掩码。侧菜单、详情和分布页沿用现有输入处理。长按重复、入口动画与重绘期间的采样时机仍在单独审计，本记录不宣称完整图鉴时序一致。

使用 25 种已见、0 种已拥有的受控存档状态，从实际 START 菜单选择图鉴；前后使用同一组输入，终点取相对帧 240。4 种场景前后均重复两次，状态和 PNG 字节一致。两组普通 DOWN 点按仍得到列表第 3 项；DOWN+A 修复后为第 4 项、scroll=1；RIGHT+A 为第 15 项、scroll=14，均与原作零售 Red 回放一致。结构化结果见 `docs/evidence/pokedex-held-413.json`。
