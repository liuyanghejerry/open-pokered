# 商店字段流程修复验证

## 行为

商店店员的首次问候由字段文本直接进入 BUY/SELL/QUIT，不再要求额外确认每行问候。买卖确认和错误文字由字段文本拥有输入；出售播放收银音效。QUIT 保留最后的 Thank you!，等 A 松开后才关闭文字并恢复地图。恢复工作依据地图实际 NPC 图形传输量计算，不复用 START 菜单额外加载文本框图形的等待。

字段 PrintFieldText 的首次显示还需要 3 帧背景提交、128 个字体图块的 17 帧传输，以及 PrintText 的 3 帧等待。后续内层字段文字只保留 PrintText 的 3 帧等待。原作对应 CopyScreenTileBufferToVRAM / LoadFontTilePatterns / CopyVideoDataDouble / PrintText；没有为时间曲线加入任意补帧。

## 交易回放与 GBA

七类交易情况各重复两次：购买成功、取消购买、出售成功、取消出售、不可出售物品、钱不足、背包满。四类出售边界各重复两次：第二组物品部分出售、整组出售、滚动列表后整组出售、金额上限 999999。背包、资金、返回光标和重复 PNG/JSON 校验均通过。

GBA 原发布构建触发 IWRAM 预算保护：24344 字节超过 24320 字节。将 Oak 场景的外层绘制函数留在 ROM，同时继续把共用 tile/font 热循环放在 IWRAM 后，发布链接通过，占用 22120 字节，剩余 2200 字节；预算及 8 KiB 栈预留没有调整。绘制算法及原作基准未改。同一修复的 GBA 性能基准通过原有 31 项预算检查，基准及阈值未改。
