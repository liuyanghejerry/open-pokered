# m01–m10 回归与主动发现 MVP

本轮只测试击败 Brock 之前可接触的内容，与其他 worktree 的 m11+ 主线扩展独立。
两条路线都复用现有游戏和调试接口；本轮不修改游戏行为，也不把新发现直接更新成“正确基线”。

## 实测结论（2026-09-08）

两条路线都能在主线通过时提供增量发现。内容路线已产生一个有明确原版依据、可重复的
行为缺陷；视觉路线以很低的复跑成本暴露稳定的跨实现画面差异，但仍需人工归因。
建议扩展内容断言作为回归检查，同时保留小规模原版视觉场景集用于审查。

| 检查 | 实测结果 | 运行成本 |
|---|---|---|
| fresh m01–m10 基线 | 一次完整通过，`EVENT_BEAT_BROCK` 达成 | 223.3 秒 |
| 内容 7 场景 × 3 次 | 18 次通过、同一场景 3 次失败；独立问题数为 1 | 合计 140.423 秒，约 46.8 秒/套 |
| 满包丢物品，追加保存重启 × 3 次 | 每次均验证未获物品、物品消失且持久化 | 合计 21.506 秒 |
| 视觉 2 个卧室状态 | 归一化差异分别为 2,974 / 2,219 像素（12.91% / 9.63%） | 独立复跑 1.771 秒 |
| 视觉校准 | 两端重复采样均为 0 差异；每次注入 8×8 区域均检出 64 像素；单纯换色归一化后为 0 | 包含在视觉运行中 |

时间只代表本机、本轮选定场景，不能以“两张静态图比七个交互快”推算全流程测试成本。
内容整套计时来自追加重启证据前的版本；新增重启分支单独跑了三次，当前整套会略慢。
内容错误预期校准把 Route 1 的奖励从 1 改为 2，经原有断言正确失败。

**行为发现：**常青森林 (25,11) 的可见 Antidote 在满包时仍被移除，数量保持 0，
拾取标志却置位；保存重启后仍丢失。主线通关不会触发这一满包边界。
详见[内容 MVP](content-regression-mvp.md)，包含固定原版源、命令和失败状态证据。

**视觉发现：**原版真实开机后到达卧室并向左移动，重制版独立构造相同位置、朝向的静态状态。
两幅截图均呈现地图水平约 8 像素偏移的候选差异，玩家区域仍有残余差异。
诊断平移不参与消除失败；尚未将这些现象分别确认为具体渲染缺陷。
详见[视觉 MVP](visual-oracle-mvp.md)及[三联对照图](screenshots/visual-oracle-mvp/bedroom_spawn-comparison.png)。

两路均以固定 pret revision `fbcf7d0e19a3a2db505440d3ccd3d40ca996c15c` 为参照；
视觉端构建 ROM 的 SHA-1 精确匹配 Red USA/Europe。
主线日志保存在 [m10-baseline.log](audits/regression-discovery-mvp/m10-baseline.log)。
此次新增的是 AI 选题、编写并调试的可复用探针，不是运行时持续自主探索的代理，
也没有完成全流程逐帧同步；这两个更大目标应在 MVP 的确定性基础上继续扩展。

## 实验设计

| 维度 | 内容 playtest | 原版视觉对照 |
|---|---|---|
| 外部预期 | 固定 pret/pokered revision 的行为规格 | 固定 ROM 的模拟器实际输出 |
| 执行 | 独立准备前置状态，再通过真实输入触发 | 两端独立到达对应场景，记录对齐依据 |
| 判定 | 背包、对象、对话、事件与持久化断言 | 原始差异、颜色归一化差异、差异区域 |
| 对照实验 | 错误预期必须被拒绝 | 相同输入自比、重复采样、人工局部差异 |
| 失败证据 | 操作、前后状态、错误、来源 | 双端图片、差异图、参数、状态与版本 |

局部状态构造只能证明该前置条件下的交互，不证明新游戏能正常到达那里。
保留 fresh m01–m10 主线作为独立可达性检查；不修改现有 milestone、scenario 或 BDD 驱动。

## 如何衡量性价比

- 分开记录首次依赖准备、场景开发和后续运行成本；本轮不以粗略开发时间推算未来吞吐量。
- 场景数、断言数与独立问题数分开统计：多条失败可能来自同一个缺陷。
- 重复失败是待诊断证据；重试通过仍记录为不稳定，不能删除失败记录。
- 区分产品差异、驱动/状态对齐错误和明确允许的差异。视觉百分比本身不能证明产品有 bug。
- 注入错误只能测量该类错误能否被检测，不能宣称总体召回率。没有完整标注集时不报告准确率。
- 内容 oracle 不从重实现当前输出自动生成；视觉基线不因为当前构建失败就自动接受。

## 后续接入原则

可稳定复现的行为断言适合进入回归门禁。尚未标注的跨实现视觉差异先作为审查产物，
为具体场景确定允许差异后再决定是否阻断。新增发现应保留最小重现与原版证据，
游戏修复另行处理；不要为让实验变绿而放宽断言。
