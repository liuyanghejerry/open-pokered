# START 菜单方向后的三帧采样等待（108）

原作 `MenuJoypad` 在方向键移动菜单光标后执行 Delay3。已有初始化和子菜单返回等待并不能覆盖这个分支；复刻原先在下一硬件帧就再次读键。

固定原作 Red 上，Down 在 120 帧使 POKEMON 变为 ITEM，Up 单帧脉冲在 121、122 帧被忽略，在 123、124、125 帧立即接受；Up 从 121 持续八帧时在 123 接受。六种输入各重复两次。

修复现在在接受方向后保留完整 Joypad 样本，等待三帧再比较当时持有的按键：等待内短按被丢弃，跨过等待持续持有的新键会被接受，一直持有的旧键不产生新边沿。方向加 A 的组合仍先处理方向；空队伍入口不会把该组合错误当作单独的 A 选择。
