## 新因子

复用主循环已有的执行前/后事实，只为成功的 `train_encounter:*` / `trained`
结果记录 `collection_training_observation`：

- 操作地点；原生 owned-bit 与每物种等级/XP 的边界比较；
- 操作结束后的实际 party 索引、物种、HP/max HP 和状态。

`collection_training_execution_reference` 统计当前控制器所有保留结果，按地点
与物种列出已知 XP 差样本数/总和、未知样本数、结束后 HP/状态警告样本数。
0 和负 XP 差均保留；重复同种、非法或缺失 XP/健康事实不被当成零成本。
同时统计“恢复目标在结果边界满足”的数量，但不归因给某个训练地点或认定
为独立治疗交易。详细列表只保留最近一次训练；全部原始结果仍在 trace，
全部统计不截断。CONTINUE 前没有重建的历史不冒充已观测。

指引让 Jev 将这些历史与剩余进化工作、公共 XP 估计和所有其他收集途径比较。
没有强制路线/队伍/目标、候选筛选、加权打分、假定胜利或预测未来耗时。
健康警告仅沿用现有 70%/状态参考，不证明受伤原因或治疗必要性。
旅行、战斗回合、PP、模型耗时未在这个因子中测量。PC 基线、失败计数、
原生资源与来源审计不因新记录而改变。
