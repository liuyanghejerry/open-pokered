# 图鉴来源记录：目标不是实际获得方式

第27段策略验证链从64到67：白海狮、臭臭泥、海刺龙。
其中臭臭泥是39级野生捕获，但当时正在执行海刺龙进化目标，旧日志直接
复制目标上下文，把它误标成 `evolution`。原始日志不改写；独立证据记录实际
捕获前后原生状态、一个新增PC个体和1精灵球、1超级球、3高级球的真实消耗。
两个实际原生等级进化也分别保留证据。

`collection_events.py` 只消费已有原生观察，不调用模型或发送游戏指令：

- 捕获必须同时匹配新登记位、野生非幽灵对战、捕获物种/等级/存活HP、
  一个新增队伍/PC成员和实际球消耗；记录 `wild_capture`。
  这个通用标签不声称已经区分草地、冲浪、钓鱼或静态来源。
- Safari额外要求原生Safari标记和对战内 `safari.balls` 减少。
- 等级进化要求原生 `IsEvolving` 阶段、已知等级边和唯一的队伍/PC物种
  替换；不依赖目标或历史队伍位置，允许真实PC转移、队伍换位。
- 石头进化要求已知道具边、等等级唯一物种替换和一枚对应道具的实际消耗。
- CONTINUE首个快照只是基线。礼物、交换和其他尚无匹配证据的获得方式
  保留 `unknown`，不会由目标或“理论上可行”推断为事实。

`dex_progress.acquisition_method` 和逐物种 `acquisition_evidence` 记录观察结果；
`planned_acquisition_method` 单独保留计划。混合方式的一次快照不会强行合并
为单一来源。原生battle事件原样保留；该收集器不清除既有来源审计、不改变
候选、资源、原生协议、模型或完成判定。
