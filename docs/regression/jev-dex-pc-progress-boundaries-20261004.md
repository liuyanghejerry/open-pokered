## 新决策因子

基础 agent 新增默认空的 `operation_outcome_observations` 钩子；普通故事目标
行为保持不变。图鉴 agent 只在成功的正常存入/取出操作时记录：

- `since_previous_completed_pc`：上次完成换队后的观测到本次操作开始前；
- `during_completed_pc`：本次执行前后，区分 PC 交换本身带来的队伍变化；
- `progress_since_last_completed_pc`：策略选择时最新事实与上次 PC 后观测的比较。

提供原生 owned 数量与新增/移除种类、各物种前后队伍索引/等级/XP 样本。
每边只有一个同种样本且 XP 已知时提供差值；缺失、非法 XP、重复同种、缺失
party/dex 或没有上次边界时保留未知。0 XP 不会被误判为缺失，负差值也不裁成 0。
重排不被解释为训练，但同种样本也不是已验证的个体身份或战斗归因。
原生 owned-bit 变化不会清除来源审计或变成合法登记证明。

策略指引只要求比较这些观测与剩余收集工作。没有强制训练、禁止 PC、
固定队伍、路线、目标排序、筛掉候选或把零观测增量当作失败计数。
所有完整事实、候选 ID/顺序、普通字符串标准和 `none` 均保留。
历史只覆盖当前控制器，不反推 CONTINUE 前的存档链。
