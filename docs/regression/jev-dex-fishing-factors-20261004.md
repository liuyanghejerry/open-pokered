# 钓鱼收益因子与第26段安全检查点

## 概率修正

原版 [`ItemUseGoodRod` / `ItemUseSuperRod`](https://github.com/pret/pokered/blob/d2704a63c26f9ba046ade877445216b3de0519a4/engine/items/item_effects.asm)
和当前原生 `roll_rod_response` 都在拒绝越界鱼表索引后，重新抽取随机字节，
再次检查无咬钩分支；并非先决定50%咬钩，再只重抽鱼种。

在独立均匀随机字节的参考模型下，n项鱼表每次合格岸边抛竿的咬钩率为
`n/(4+n)`，每项鱼种出现率为`1/(4+n)`。Good Rod与两项Super Rod鱼表为
1/3，三项为3/7，四项仍为1/2。Old Rod固定Magikarp，保持不变。
15个收益配置修正；原生钓鱼逻辑和鱼表物种/等级未改。

为Jev分别提供每竿无咬钩率、已登记鱼种出现率、未登记鱼种出现率和期望
抛竿次数；`*_encounter_share_pct`明确为咬钩后的条件比例，与草地字段语义一致。
目标鱼种也补充条件比例。遇见不是捕获，不是耗时估计或保证登记；此数学
参考不能当成所有原版硬件随机序列均独立的证明。
