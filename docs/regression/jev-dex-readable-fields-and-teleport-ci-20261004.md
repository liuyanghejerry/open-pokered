## Teleport CI 失败

CI run `37205003337` 的原生包测试在
`battle::recharge_lifecycle_tests::teleport_flees_a_wild_battle` 失败。
该测试从熵创建战斗 RNG，却要求每次 Teleport 都成功。

在相同普通野生战斗夹具中固定随机种子，旧断言在种子 4 稳定失败。
其前几个随机字节为 `228,166,255,3,101,183,95,64`；前两次是
AI 判定与敌方选招，第三次 255 是 Teleport 的命中判定。
实际文本为 `ABRA used\nTELEPORT!` 后接 `ABRA's attack\nmissed!`，
下一阶段正常回到玩家菜单。这符合生产命中实现保留的 Gen-I 1/256 miss，
不是此次 Python 策略改动引起的游戏机制回归。

修正仅位于 `#[cfg(test)]` 测试模块：

- 固定种子 0 核验野生战斗 Teleport 成功逃走，并消耗 1 PP。
- 固定种子 4 核验未命中，战斗继续、双方 HP 不变，仍消耗 1 PP。
- 固定种子 0 核验训练家战斗不被 Teleport 结束。

没有改动生产命中、逃跑、等级判定、动画或原版 bug。
策略实跑继续使用此前验证过的原生二进制，不因测试修正替换游戏。
